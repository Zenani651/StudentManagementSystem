# Student Management System

A web application for managing the day-to-day records of a school or university. Administrators can register students, lecturers, departments and courses, enroll students in courses, and see an overview of the whole institution on a dashboard.

Users log in with role-based accounts (Admin, Lecturer and Student), so each person only sees and does what their role allows.

Built with ASP.NET Core MVC, C#, Entity Framework Core and SQLite.
